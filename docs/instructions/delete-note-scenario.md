
# Пользовательский сценарий «Удаление заметки»

## Действующие лица

1. Пользователь.

2. Приложение.

3. Бэк.

4. База данных.

## Предварительные условия

Пользователь должен находиться на главном экране.

В системе должна быть хотя бы одна заметка пользователя.

## Выходные условия

Выбранная заметка удалена из системы и не отображается в списке заметок.

## Основной сценарий

1. Пользователь выбирает заметку из списка.

2. Приложение открывает выбранную заметку в режиме просмотра.

3. Пользователь нажимает кнопку **Удалить**.

4. Приложение открывает окно подтверждения удаления с сообщением «Удалить заметку?».

5. Пользователь нажимает кнопку **Да**.

6. Приложение отправляет Бэку запрос на удаление заметки.

7. Бэк удаляет заметку из Базы данных.

8. Бэк возвращает Приложению ответ об успешном удалении заметки.

9. Приложение открывает пользователю уведомление «Заметка успешно удалена!».

## Альтернативный сценарий

1. Пользователь выбирает заметку из списка.

2. Приложение открывает выбранную заметку в режиме просмотра.

3. Пользователь нажимает кнопку **Удалить**.

4. Приложение открывает окно подтверждения удаления с сообщением «Удалить заметку?».

5. Пользователь нажимает кнопку **Нет**.

6. Приложение закрывает окно подтверждения удаления и открывает выбранную заметку в режиме просмотра.
