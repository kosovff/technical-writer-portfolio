# О продукте

**TaskFlow** — веб-сервис для управления задачами и организации совместной работы команды.

С помощью TaskFlow пользователи могут:

- создавать и редактировать задачи;
- назначать ответственных;
- устанавливать сроки выполнения;
- изменять статусы задач;
- отслеживать выполнение задач;
- организовывать совместную работу команды.

Система доступна через веб-браузер и не требует установки дополнительного программного обеспечения.
