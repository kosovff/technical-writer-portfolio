# Портфолио технического писателя

Привет! Здесь собраны примеры технической документации, созданные в рамках учебного проекта.

Портфолио построено по подходу **Docs as Code** с использованием Markdown, MkDocs и Git.

## О проекте

**TaskFlow** — учебный веб-сервис для управления задачами команды.

В рамках проекта подготовлены разные типы технической документации:

- руководство пользователя;
- пошаговые инструкции;
- описание API;
- диаграммы процессов;
- примеры работы с интерфейсом.

## Что демонстрирует проект

В проекте используются:

- Markdown;
- MkDocs Material;
- Git;
- GitHub;
- OpenAPI;
- Mermaid;
- Docs as Code.

## Разделы документации

### Руководство пользователя

Описание основных возможностей TaskFlow и сценариев работы с сервисом.

### Инструкции

Пошаговые инструкции для выполнения отдельных задач.

### API

Описание REST API, методов, параметров запросов и ответов.

### Диаграммы

Визуальное описание процессов и взаимодействия компонентов системы.

## Обо мне

Я развиваюсь в направлении технической документации и создаю понятные материалы для пользователей и разработчиков.
